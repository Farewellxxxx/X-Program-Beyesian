# BO-only 人体可行性研究交接（与模拟比较分开）

本交接只提出后续研究设计，不建立人体试验界面，也不把模拟胜负转写为人体优势。拟研究的问题是：在既定安全与伦理框架内，单一 Bayesian adaptive boundary estimation 流程能否获得可理解、可执行、可独立验证的个体化加速度可接受性边界。人体阶段只部署 BO，不能声称与 UCB 或 staircase 的人体比较效果。

## 入组前冻结

由实际研究团队完成伦理审批、设备与场景风险评估、筛选/退出机制和运行上限；这些上限不能由模拟的 [0,3] m/s² 或先验支持范围代替。明确受试者所回答的“可接受”含义、情境和时间窗口；tau=.70 与 delta=.15 是模拟操作值，应根据研究目的及独立依据另行论证，不能称为已验证的人体容忍标准。目标命令、实测加速度及反馈分别记录；执行偏差本身不删除有效实测试次。

在看人体最终数据前冻结：BO先验与参数网格、允许命令集、独立执行标定方案、试次上限、checkpoint、参与者级主要终点、独立验证强度与次数、失败和删失处理、停止/退出规则、数据排除原因及版本哈希。独立执行标定的测量次数单独报告，不能藏在较小的反馈试次数之外。明确模拟主事件是预算末端回看后定义的持续准确性，人体在线流程无法直接使用未知真实边界或未来反馈作停止条件。

## 校准与独立验证

校准期只使用该参与者自己的历史反馈及实测加速度更新模型。单次 Bernoulli 反馈、重复反应差异和后验边界不确定性分别解释，不用历史多数表决替代原始反馈。记录所有有效测量及拒绝/不适、退出、设备失败和模型支持不足；全接受或全拒绝时保留相应支持标签，不强制输出域内“成功阈值”。

独立验证期冻结校准得到的报告，不再将验证反馈用于更新同一主分析估计。按照预注册规则，在估计边界附近和上下的可实现且获准强度上收集新的验证反馈，记录实际加速度；可随机化验证顺序并保持明确的暂停/退出渠道。分析实测强度上的可接受率与预测是否一致，报告二项抽样不确定性和估计边界附近的证据密度。单个反馈不能提供真实 B_tau；需要重复且独立的数据，或另一个预先定义的验证模型与区间。独立验证即使不支持校准，也应完整报告。

## 可行性与体验结果

以参与者为汇总单位报告完成率、有效反馈试次数、独立标定与验证负担、实测总时长、退出/暂停及其原因、原始不可接受反馈比例、目标/执行偏差、边界后验区间与支持、验证表现，以及对问题可理解性和流程体验的反馈。实测耗时来自实际记录；不能把模拟试次数换算成实测节省时间。模型覆盖率在真实未知边界下通常不可直接验证，应避免用模拟覆盖率替代人体验证。

最终证据结构应明确分开：模拟提供机制受控的算法采样效率比较；BO-only 人体研究提供部署可行性、体验和独立验证证据。若未来需要人体方法优劣结论，须另行设计有合适比较组、顺序/学习效应控制和样本量依据的研究。
