# Reproduce the decoupled calibration study

From the repository root, use the pinned simulation dependencies in requirements-simulation.txt. Set numerical library threads to one before starting Python. The CLI default config is configs/decoupled_pilot.json; always provide a fresh output directory. Nonempty directories are refused, including partially failed runs. No implicit overwrite is supported.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -m comfort_boundary_bo_research_package.simulation.decoupled_calibration --config configs/decoupled_pilot.json --output outputs/decoupled_pilot
python -m comfort_boundary_bo_research_package.simulation.decoupled_calibration --config configs/decoupled_heldout.json --output outputs/decoupled_heldout
```

The pilot has two passengers per family/execution cell and development seed1105. Held-out seed271828 is separate and initially specifies32 per cell. The coordinator chooses and freezes held-out n before evaluation using measured pilot runtime (bounded16–32 per cell), with no tuning for comparative outcomes. Five methods include four primary samplers and ucb_tau reward sensitivity. All receive31 common target commands on [0,3], tau=.70, a common Bayesian reporting model fitted to each method's own realized observations, and60 passenger trials. Tau is an illustrative synthetic criterion; delta=.15 is5% of the physical domain, not an empirically validated human tolerance. Save any changed frozen config with provenance before running. Never silently replace a completed result.

A shared independent vehicle calibration has90 auxiliary measurements per passenger/execution condition, reused by all methods. Those are vehicle measurements, excluded from passenger feedback trial counts; they are a real auxiliary data cost and are not evidence of free human trials. A vehicle calibration is condition-specific. Population curves are paired across execution conditions and methods. Stable IDs are family logistic=1,probit=2,lapse_logistic=3; execution precise=1,variable=2; methods bayes_risk=1,bayes_point=2,ucb_tvcg=3,ucb_tau=4,staircase=5. Population key is family*1,000,000+participant; execution key adds execution*10,000. Semantic stream IDs are documented in decoupled_simulator.md. Dictionary/list iteration order cannot change a method's stream.

The runner writes exact normalized config.json and its SHA256 hash before random draws. effective_parameters.json also freezes complete effective PolicyConfig and PriorGrid support/means/SDs/node counts, population defaults, and SHA256 hashes of simulator, policy, public-interface and inference source files. These source hashes pin policy constants in addition to user-specified parameters. summary.json records calibration_measurements_per_participant_condition and total_calibration_measurements; calibration is repeated per passenger/condition and shared across methods. trials.csv contains every trial's public target, realized measurement, response and estimator summary plus evaluator errors/coverage. participants.csv contains participant-method endpoint and final metrics. truth.json is a separate private audit record with hidden passenger/vehicle truth and public calibration estimates, never passed to policies. summary.json records run dimensions and endpoint names. Schema keys use scenario,family,execution,participant,method as identifiers; trial is one-based. Trial estimate is the scalar boundary estimate, lower/upper its95% interval, covered its truth inclusion, and edge_mass the posterior grid-edge diagnostic.

The primary event is the first t>=10 whose entire t..budget suffix is within delta of truth and contains at least five estimates. The secondary event is first t>=10 ending five consecutive accurate estimates; later relapse is allowed for this secondary metric. These are offline truth-based retrospective endpoints, never deployed stopping rules. An absent event is blank in CSV, observed=False and cost=budget. Cost is for restricted-mean calculations across all passengers, never successes only. Budget60 means the primary event can occur no later than56. Sequential correlated estimates do not constitute independent confidence.

Participant interval_coverage and interval_width refer to the final interval. Overestimated means final signed error>delta; unidentifiable flags constant response histories, final boundary support outside the observed range, or truth outside the physical domain. Preserve these rows. The optional boundary_override config key supports separately labeled out-of-domain stress tests, which must not be pooled into main scenarios. Estimates are never clipped to the physical domain. Summaries and bootstrap uncertainty must use passengers within scenarios as units and preserve method pairing; individual trials are not independent replicates.

Tests: `python -m pytest tests/test_decoupled_passenger.py tests/test_decoupled_execution.py tests/test_decoupled_study.py --basetemp tmp/passenger-worker/combined-final -q` with TMP and TEMP set to repository tmp/passenger-worker. Tests include a reduced-grid smoke config; frozen run grids remain81x41 and acquisition quadrature7. Simulation comparisons are algorithm sampling-efficiency evidence and cannot establish human comparative effectiveness.
