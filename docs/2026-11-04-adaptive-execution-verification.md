基线 `33e01230d284cf585a25234bfb46b9738f5a09df`，隔离发布目录分支 `feature/adaptive-execution-posterior`。Python 3.12.7、NumPy 1.26.4、SciPy 1.13.1、pandas 2.2.2、matplotlib 3.9.2、pytest 7.4.4；SciPy 原已安装，本轮补入固定依赖。全部实验为合成数据。

## 测试与数值推导

历史 81 项测试保持通过。五个核心测试先因推断模块不存在而失败，随后通过；四个预测适配/独立区间诊断测试先因模块不存在而失败，随后通过；审计/接口三项测试加入后完整测试为 **93 passed**。有一次审计测试的临时目录设置沿用 Windows 默认路径而报错，恢复本项目既有 TEMP/TMP 设置后通过，不涉及产品代码修改。

覆盖的实质检查包括：独立多元 Student-t 边际密度与共轭证据相等；后验 m/V/a/b；单调约束概率与独立大样本 t 分布抽样一致；含先验正规化的约束证据；联合 sigma²/eta 的矩、Sigma 的条件/边际方向；SPD 与每次 beta 抽样单调；不可写数组；抽样数量改变时的精确前缀；无效、秩不足和零噪声记录；全概率方差公式；标量/批量及时间项一致；改变隐藏真实参数不影响同观测后验；固定策略物理轨迹逐值一致；独立未来样本和手算区间评分；CLI 来源字段及旧/新/备用响应模型输出路径隔离。

比较层检查缺少完整场景、策略或预测方式，缺命令点、错 holdout namespace、错误种子/参数/权重/指纹、负区间宽度及不一致区间字段。完整脚本按声明场景验证 manifest、校准前缀、历史原字段及六个完整网格，再重算后验与每种预测器身份。

核心矩测试最初用任意绝对容差 0.008，观测 Monte Carlo 差 0.010。改用独立多元 t 四阶矩推导的五个标准误差界，产品算法未改；精确线性代数与证据检验继续约束参数化。

## 集中后验的数值边界修复

正式实验结束后，增加 2,400 行确定性复制记录的集中后验压力测试。这是数值夹具，不把复制记录当作独立科研证据。测试先复现无限区间积分漏掉密度中心而无法正规化；修复后又复现极小模型权重下溢为零导致 `0 log 0` 为 NaN。

积分在曲率零点远离密度中心时，增加中心分段交叉核验；原积分与中心分段在既定 1e−9 容差内一致时保留原值。模型熵只对正权重求和，零权重项取极限 0。压力测试确认集中二次后验的约束概率约为 1，且熵有限。修复后完整测试 **94 passed（21.49 秒）**。

使用七个独立 worker 从磁盘校准记录重算全部 280 组主实验后验，逐值精确比较所有后验 metadata：模型权重、约束质量、证据、均值、协方差、熵、种子和抽样内容指纹全部相同。该修复没有改变主实验的任何预测器参数或随机抽样库；无需重复其反馈轨迹。完整比较再以最终代码重算检查各组拟合。

## 实验和逐记录检查

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
python -m pytest -q
python long_horizon_audit/scripts/run_adaptive_execution_audit.py --workers 8
python long_horizon_audit/scripts/compare_adaptive_execution.py
python comfort_boundary_bo_research_package/simulation/run_uncertain_input_bo_extended.py --execution-estimator adaptive_posterior
python comfort_boundary_bo_research_package/simulation/run_uncertain_input_bo_poc.py --execution-estimator adaptive_posterior
```

主运行退出码 0：280 个新场景＋280 个前版重放，共 806,400 次反馈；前两组约 1478.7 秒，随后完成 14 个敏感性单元×3 组设置。八个 worker 仅影响调度，不参与种子派生。无场景被排除或因拟合失败跳过。

独立逐记录核对 33,600 条新个体汇总，重新聚合到七项策略指标及协议偏离率，最大差 0；840 条分组保存的人群记录由种子重建后逐值相同；校准总记录 15,960 条。840 行是七个条件重复保存相同五批人群，不是 840 个独立人群样本。

全部 280 组校准无触边记录排除。二次候选最小单调后验质量约 0.1593，最多使用 13,056 次联合提议得到 2,048 个接受抽样，远低于固定 200,000 次上限。没有把失败候选删除或把非单调抽样投影成后验。

扩展示例生成 2,880 条反馈和两组拟合，POC 生成 900 条反馈和一组拟合；各有八张 CSV、九张 PNG。18 张 PNG 均可解码，检查了扩展示例精度/代价图与 POC 个体轨迹图；六张主对比图分别检查均值误差、独立覆盖率、宽度、评分、最终边界误差和不可接受反馈。
