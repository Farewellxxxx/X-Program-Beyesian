## 本轮独立参照的含义

生产代码保留已有 NumPy／标准库概率公式，参考核验由 SciPy 1.13.1 的独立分布实现及解析反算组成。参考脚本必须自行构造位置、尺度与反射，不能调用生产概率函数来构造预期值。应记录实际库版本与所用模块哈希；通过该核验意味着数值和参数定义一致，不等于获得人体效度。

不复制 psignifit 源码到运行模块。该包代码为 GPL-3.0-or-later；本轮借鉴已公开的数学定义、引用原始来源，并使用项目已有 SciPy 做独立参照，不新增完整 AEPsych／psignifit 运行依赖。

## 唯一新增曲线及方向

静态 Gumbel 生存函数候选采用

`p_accept(x) = exp(-exp(z))`,
`z = log(-log(tau)) + k * (x - B)`,
`k = (log(-log(0.2)) - log(-log(0.8))) / W`。

它对应 `scipy.stats.gumbel_l.sf(z)`，满足接受概率随实际加速度下降，`p_accept(B)=tau`，80% 到 20% 的实际加速度宽度为 W。它是 psignifit Gumbel CDF 的补事件形式；不是简单把刺激轴反向，两种处理的偏斜方向不同。本轮预先固定这一方向，不能根据结果选择对 BO 更有利的反射。

匹配 B 与 W 后，不同族的局部斜率、尾部与信息量仍可不同，需明确报告。新增曲线用于模型形式敏感性，不称为更真实的乘客。

## 后续最小真人预试：用于辨认假设，不作方法优越性验证

本节是设计建议，尚未实施，也不是样本量效能保证。

1. 先固定问题措辞和一次刺激的含义；明确实际加速度采用什么时间窗、峰值／均值等特征，并尽量控制持续时间与 jerk。仿真 0–3 m/s² 的计算域不能直接称为已验证的实车试验范围。
2. 可以先做少量参与者的可行性预试，例如 8–12 人。这个规模用于发现流程问题和估计参数的大致范围，不用于证实 BO 比其他方法更高效，也不能精确识别每个人的 lapse。
3. 每人先在实际可用范围内覆盖低、中、高等若干强度，并在同一强度安排重复反馈；使用平衡／随机顺序，记录目标、测得的完整实际轨迹、回答、试次顺序与休息时间。若初始范围没有覆盖接受／拒绝两侧，保留为不可辨认，不强制拟合一个有限边界。
4. 优先判断：接受概率是否大体单调；同强度回答是否稳定；B 与 W 是否能识别；前后时段或前一刺激是否产生明显变化。小样本不同时自由估计所有复杂参数；报告不确定性和不能识别的参数。
5. 通过这些记录约束后续模拟的人群范围，并明确哪些参数仍只能做敏感性分析。任何模型选择使用预试数据；正式效果验证使用独立参与者／预留数据。
6. 正式 BO 可行性研究需另设独立验证反馈或重复测量来评估预测和稳定性。真人的 B 无法直接观测，不能把有限次参考测量当无误差真值；只有 BO 单臂时不提出相对 staircase 的真人效率优胜结论。

静态模型若与预试明显冲突，再单独定义动态边界的目标与评价规则；本轮不提前引入这些机制。
